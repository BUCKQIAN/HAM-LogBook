# v1.2.0 开发记录

状态：开发中，尚未发布。应用版本 1.2.0，Android versionCode 12；调试安装包使用独立的 `xin.anji.hamlogbook.debug` 包名和 `1.2.0-debug` 版本名。

## 本次改动

- 设备预设、亚音和各页的下拉选择统一使用应用内列表，带筛选、取消和键盘操作；保留手动输入。每次打开读取当前候选值，返回缓存页面时刷新设备列表，避免依赖 WebView 原生候选弹窗。
- 记录页“信号和频率”增加“默认频率”和“从中继台选择”。中继列表分别显示接收、发射频率，选择后识别频段。
- “通联信息”增加整行“使用默认设备和功率”。在设置 → 台站资料与预设保存默认频率（MHz）、设备及功率（W）；仅在点击时填充，未配置的字段保留手填内容。
- 支持 HamQTH / QRZ 查询源和账号验证。Android 查询直接使用 CapacitorHttp，QRZ 密码通过 POST 提交，凭据使用 Android Keystore 加密保存。
- HamQTH 异常经纬度不会中断有效姓名、QTH 和网格的填充；查询过程中更改呼号会丢弃旧结果。网格优先使用服务返回的有效值，坐标仅用于缺少网格时补算。
- 个人信息备份升级为 schema 4，保存新增默认值、查询源及用户名，兼容 schema 1 / 2 / 3。新备份排除两种平台的密码，旧备份中的明文 HamQTH 密码只在 schema 1 / 2 的迁移中读取。
- 修正新建 QSO 页面错误显示“删除 QSO”按钮的情况；编辑记录时显示。

## 查询源调查

Wavelog 的 [接入文档](https://docs.wavelog.org/user-guide/integrations/callsign-lookup/) 和 [QRZ 接入源码](https://github.com/wavelog/wavelog/blob/master/application/libraries/Qrz.php) 同样通过 XML 登录、缓存会话并查询呼号。其文档提到普通 QRZ 账号可以返回部分姓名和城市字段；[QRZ 官方规范](https://www.qrz.com/docs/xml/current_spec.html) 将未订阅账号定位为有限测试访问，完整资料需要 XML 订阅。因此本应用允许普通账号尝试并填入实际返回的资料，不承诺字段齐全或持续可用，也不会自动购买订阅。

[HamQTH 官方文档](https://www.hamqth.com/developers) 说明旧 XML 接口仍支持现有应用。2026-10-05 实际读取未登录接口，得到 HTTP 200、XML“Username or password missing”和允许跨域的响应头。只能据此确认接口可达及响应格式；没有真实账号时不能证明完整登录和查询可用。本次保留免费 HamQTH 默认源并增加 QRZ 选项。

[Callook](https://callook.info/) 面向美国呼号；[HamDB](https://hamdb.org/) 首页列出的范围为 AU、CA、CZ、DE、US，不能据此作为中国呼号的通用替代。[LoTW 官方接口](https://lotw.arrl.org/lotw-help/developer-query-qsos-qsls/) 查询的是账户的 QSO/QSL 记录，不是同类公开呼号资料库。

## 已完成的验证

- 43 项 Node 测试，包括默认值校验、收发频率区分、异常坐标和新旧个人信息备份。
- 独立 Chromium 浏览器回归：默认填充、中继选择、三轮真实页面切换、返回后预设刷新、筛选与取消；使用模拟账号和数据库验证 HamQTH/QRZ 登录、过期重试、资料填充及旧查询结果丢弃。
- 320 / 390 / 768 像素宽度的页面无横向溢出；390 像素页面截图已人工检查。
- Android Debug APK 构建及 `lintDebug` 通过，APK 签名和 16 KB 对齐核验通过。离线首次检查缺少测试依赖，按原有版本补齐缓存后完整检查成功。

浏览器回归脚本为 `scripts/smoke-test-browser.mjs`，需要可用的 Playwright 和 Chromium。默认从 Node 模块路径读取 Playwright，也可用 `HAMLOG_PLAYWRIGHT_MODULE` 指定其 `index.mjs`，用 `HAMLOG_CHROMIUM_EXECUTABLE` 指定浏览器可执行文件。运行：

```bash
node scripts/smoke-test-browser.mjs
```

测试仅使用模拟数据，截图输出到被 Git 忽略的 `dist/v1.2.0-browser-check/`。

## 真机验收

1. 安装 Debug 包，可与正式版并存。正式版日志需要通过 ADIF 导出后导入调试版。
2. 保存两台设备、默认频率和功率。在主页填充一次，再依次切换历史、中继、设置并返回，反复选择设备、模式、频段、QSL 和亚音。
3. 添加收发频率不同的中继，分别选择接收和发射选项，核对频率和频段。
4. 填写呼号后使用快捷填充，暂时离开并返回，确认草稿内容保留；编辑旧 QSO 时确认保存的是填入的新值。
5. 使用真实 HamQTH 账号“保存账号 → 验证账号 → 查询已知呼号”，确认姓名、位置和网格。断网、账号错误、呼号不存在时应给出提示，仍可离线保存。
6. 可选用普通 QRZ 账号尝试有限查询；没有返回资料时按提示处理。QRZ 订阅账号的完整查询仍需要实际验证。
7. 导出并恢复个人信息备份，核对新增预设、中继和查询源；账号密码需要重新填写。导出 ADIF 时功率应为数值，例如 `<TX_PWR:1>5`。

浏览器模拟和成功构建不能替代 Android WebView、Keystore、SQLite 及真实查询账号的验收。测试通过前，v1.2.0 不作为正式发布版本。
