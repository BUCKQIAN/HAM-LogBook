# HAM Logbook v1.1.0 更新说明

发布日期：2026-08-11

## 原始发布包的安装须知

**v1.1.0 不支持覆盖安装旧版本（包括 v1.0.0），请先备份数据，再卸载旧版并安装本版本。**

1. 卸载前导出 ADIF 日志；如果旧版支持个人信息备份，请同时保存。确认备份文件已保存在应用之外。
2. 卸载旧版后安装 v1.1.0。卸载会删除应用内的日志和设置，不能依靠安装新版自动保留数据。
3. 安装完成后导入 ADIF，并恢复个人信息备份或手动重新设置台站资料。HamQTH 密码需要重新填写。

## 本次重点

### 更可靠的数据管理

- ADIF 可导出到用户选择的文件夹，系统授权会被保存。
- 修复日志分享失败和大型日志一次性占用过多内存的问题。
- ADIF 导入采用流式解析、分批写入和整文件事务：任何阶段失败都会回滚本次导入。
- 可选择每日自动生成 ADIF 备份，最多保留最近 7 份；该选项现在使用紧凑开关，整行均可点击。
- 可保存和恢复个人信息，包括中继台、台站呼号、操作证类别、默认 QTH、HamQTH 用户名和设备预设。

### 长期日志优化

- 历史页面使用索引和游标分页，不再依赖越用越慢的全表偏移查询。
- 页面仅保留最近渲染的 1000 个项目，减少大量记录导致的 WebView 内存压力。
- 呼号筛选改为前缀查询，可使用数据库索引。
- 大型 ADIF 导入设置 256 MB、100 万条记录和剩余空间安全上限。

### 通联记录体验

- A 类操作证固定提供 6m、2m、70cm；B/C 类提供完整频段列表。
- 可手动查询同一呼号的历史资料，选择并填入对方设备、天线、地址等信息。
- “是否考虑交换 QSL”会在历史记录 RST 后显示为 `PSE QSL` 或 `NO QSL`。
- 离开新建 QSO 页面时，只有已填写呼号才会提示；可选择删除草稿、暂时离开或继续通联。
- 自动草稿已加密，空白表单和自动生成的时间不会形成无效草稿。

### 安全和隐私

- 日志数据库使用 SQLCipher 加密。
- HamQTH 密码和草稿使用 Android Keystore 保护。
- 个人信息备份默认使用用户口令加密，并始终排除 HamQTH 密码。
- 精确经纬度默认不写入 ADIF；需要时由用户主动开启。
- 禁止明文网络、WebView 文件访问、混合内容和发布版网页调试。
- 分享缓存会在系统分享流程结束后删除。

## 备份文件说明

- ADIF 是开放交换格式，不加密，适合恢复 QSO，但请保存在可信目录。
- 个人信息 JSON 不包含 QSO 日志，也不包含 HamQTH 密码。
- 忘记加密个人信息备份的口令后无法恢复，请妥善记录。
- Android 系统自动备份已关闭；卸载应用或清除应用数据仍会删除本机日志。
