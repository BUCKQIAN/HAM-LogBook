# HAM Logbook v1.2.0 更新说明

发布日期：2026-10-05。正式安装包和校验文件见 [v1.2.0 Release](https://github.com/BUCKQIAN/HAM-LogBook/releases/tag/v1.2.0)。

## 本次更新

- 修复从其他页面返回后设备预设、模式、波段及中继台亚音等选项无法选择的问题，各页统一使用应用内列表，支持筛选和取消。
- “信号和频率”增加同一行的“默认频率”“从中继台选择”“优秀信号”。优秀信号一键将我方发送和接收填为 59；中继台频率选项明确区分接收和发射。
- “通联信息”增加“使用默认设备和功率”。在设置 → 台站资料与预设保存默认频率、设备和功率后，可在记录页一键填入。
- 输入频率时即时识别波段，例如 144.370 MHz 对应 2m、439.650 MHz 对应 70cm。仍遵循操作证类别的可选波段范围；未知频率可手动选择。波段列表不再显示“选择频段”占位项。
- 中继台支持编辑名称、收发频率、收发亚音、位置和备注，可保存修改或取消编辑。
- 呼号查询新增“QRZ.com（普通账号只能有限查询）”，保留免费 HamQTH。查询可填入返回的姓名、QTH 和网格，字段受账号权限及呼号资料影响；QRZ 完整资料需要 XML 订阅。
- 修正查询异常坐标的处理，避免更改呼号后被旧查询结果覆盖。Android 查询账号凭据使用 Keystore 加密保存。
- 个人信息备份包含默认频率、设备、功率及查询源，兼容旧版备份；备份不包含 QSO 日志和查询密码。
- 修正设置主页的多余下滑，改善页面安全区和启动期间系统栏配色。小屏、横屏或大字体仍可在内容区滚动。
- 修正新建记录时错误显示“删除 QSO”按钮的情况。

## 安装与数据恢复

**原先发布的 v1.0.0 / v1.1.0 使用旧签名，不能被本版覆盖安装。请先备份，再卸载旧版并安装本版。**

1. 在卸载前导出 ADIF 日志，以及个人信息备份（如旧版支持），确认文件已保存在应用之外且可读取。
2. 卸载旧版，安装 `HAM-LogBook-v1.2.0-release.apk`。卸载会删除应用内的数据。
3. 导入 ADIF，恢复个人信息备份或重新填写台站资料；HamQTH / QRZ 密码需要重新填写。

已经安装 2026-10-05 正式密钥重打包版的用户：本版与重打包版使用相同包名及证书，内部版本号从 10 / 11 增加至 12，具备覆盖升级条件，但尚未完成真机升级后数据保留验证。建议先备份，再按上述步骤安装和恢复，不建议降级。

v1.2.0 Debug 测试包的包名为 `xin.anji.hamlogbook.debug`，可与正式包并存；日志和设置不会自动转入正式包，需要导出后导入。确认正式版数据完整后再卸载测试包。

## 已知问题与验证范围

- **冷启动页问题仍未解决。** 系统冷启动画面与用户选择的完整启动页可能显示不符合预期，本版不将其列为已修复项。
- HamQTH / QRZ 已用模拟接口验证登录、过期重试和资料填入；真实账号、权限及网络环境仍需用户验证，不保证每个呼号都返回完整资料。
- 49 项 Node 测试、7 项原生单元测试及浏览器回归通过；Release 构建与静态检查通过，正式证书、包名、版本及 APK 资源已核验。维护者已简单测试正式包并确认发布；数据库升级、ADIF 导入导出和恢复尚未提供逐项验收记录。详细结果记录在附件 `BUILD-v1.2.0.json`，自动测试和成功构建不能替代这些真机验收。
